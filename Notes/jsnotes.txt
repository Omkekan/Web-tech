*How to display Output in Javascript
1.document.write():it display Output on webpage.it will display output in same line

*Variabels in java 
-it is use to store data in it.
-store data canbe change any time.
-in js to declare a Variabels we can use var,let,const keyword.

*var:
-it create function scope variable.
-we can use variable befare declaration of it.
-we can perform re-declaration of variable 

*let:
-it create block scope variable.
-we can not use variable befare declaration of it.
-we can not perform re-declaration of variable.

*const
-it create constant variable,whoes value can not change during runtime
-at the time variable declaration we have to initialize variable.


*Hoisting: it is default Javascript behaviour which moves variable declaration at top of page.
